# FInan-Exercises-with-answers
These are the solutions to the exercises in  Finan’s textbook for actuaries titled *A Basic Course in the Theory of Interest and Derivatives Markets*.

Often, when we study, we don’t see how to solve an exercise, and it’s always helpful to have a guide. 
The goal is to understand the process of arriving at the solution. 
All feedback is welcome to help improve each exercise.
